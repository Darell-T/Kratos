## Design calls made (also in the PR body when it is rewritten)

- Every turn runs `approvalPolicy: untrusted`, `approvalsReviewer: user`, and a Kratos permission
  profile (`kratos-plan`, `kratos-ask`, `kratos-approve`, `kratos-full`), each denying
  `KRATOS_HOME`. Measured on Codex 0.159.1: `untrusted` sends every command to Kratos.
- Requests during a turn are decided by the settings the turn started with (D87).
- A context-limit change reloads the thread (`thread/unsubscribe` then `thread/resume` in one
  task) before the next turn.
- After a restart, threads with uncertain messages are loaded so Codex's history settles them; a
  settled message pauses the queue as Interrupted when messages wait.
- A continuation goes back to the user when a message waits on them, the pause is not the
  limit's, or the queue is full (D85 and D11 over D39 automatic resume).
- The client token is new on each engine start; clients reread `<KRATOS_HOME>/client-token` per
  request, so they follow restarts. A refused body is drained before the 401, as the 413 is.
- Tests use short deadlines and a hand-moved clock instead of tokio's paused clock, because
  fake-codex is a real process and SQLite runs on its own thread. This deviates from the plan's
  wording.
- On Unix a SIGKILLed engine leaves Codex's children behind (documented in kratos-process as
  later work, D17); the Unix test covers Ctrl+C shutdown only.

Open question for Darell: text typed into a running shell (`write_stdin`) never reaches Kratos.
Default chosen: ask before any bare shell or interpreter starts, under every permission.

## Working rules carried over

- Do not merge PRs. Do not commit memory files, conversation history, credentials, or personal
  data; the repository is public.
- No co-author trailers or generated-by lines in commits or PRs.
- Branch names describe the work; never `claude/` or `codex/` prefixes.
- At most one subagent per turn.
- Sandbox tests must run a real process through Kratos's real path and show the block (D99).
- Mutation scripts need a per-mutant timeout, and must run on a copy of the tree, never the
  working tree.
- Writing style: no em dashes, no mid-sentence colons.
